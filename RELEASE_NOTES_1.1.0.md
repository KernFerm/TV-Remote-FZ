# TV Remote FZ 1.1.0

- Quick now has a dedicated Power/Mute/Input row with paired Volume and Channel controls.
- Numbers now uses conventional 1-2-3, 4-5-6, 7-8-9, and dash-0-enter positions.
- Media uses two rows of large icon controls.
- Extra commands use readable full-width rows with safe truncation.
- Page indicators live in the header, and Navigation helper text no longer overlaps the D-pad.
- Directional focus follows the actual geometry of every page.
